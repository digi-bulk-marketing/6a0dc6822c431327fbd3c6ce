## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/6a0dc6822c431327fbd3c6ce/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **VORTEX 10 PRO** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/6a0dc6822c431327fbd3c6ce/releases/latest) and reinstall.
